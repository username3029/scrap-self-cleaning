Welcome to Scrap

The self-cleaning Downloads folder you've always wanted.

Scrap creates a special folder called Scrap inside your Downloads. Every file you put there is automatically permanently deleted after 24 hours.

⚙️

How It Works

1
Right-click any download link in your browser and select "Download to Scrap".
2
The file lands in ~/Downloads/Scrap.
3
Move important files out of Scrap within 24 hours. Everything else is permanently deleted.
🖥️

Step 1: Desktop App

The Scrap desktop app runs in your system tray, monitors the folder, and automatically deletes old files.

Install dependencies:

cd scrap && pip install -r requirements.txt

Then run:

python -m desktop_app.tray_app
🧩

Step 2: Browser Extension

Install the Scrap extension to right-click and download directly into your Scrap folder.

1. Open chrome://extensions

2. Enable Developer mode (top-right)

3. Click Load unpacked

4. Select the scrap/extension folder

🎉

You're All Set!

Scrap is now running. Any file you download to Scrap will be permanently deleted after 24 hours.

💡 Pro tip: Keep the Scrap folder pinned in your file manager for easy access.
